# Chemical Equipment Visualizer

A hybrid web and desktop application for uploading chemical equipment data, generating summary statistics, exploring interactive charts, exporting PDF reports, and reviewing analysis history.

## Features

- CSV upload and structured data processing
- Summary statistics and interactive visualizations
- PDF report generation
- History management for previous analyses
- Web interface and desktop workflow

## Technology

- Django REST API
- React frontend
- PyQt5 desktop interface
- Matplotlib for analysis and charts

## Demo
